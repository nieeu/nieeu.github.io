<p>In modern financial mathematics, the Black-Scholes assumption of constant volatility often fails to capture real-world market dynamics, such as the volatility smile. The Heston model addresses this by assuming volatility itself follows a random process.</p>

<h2>1. The System of Equations</h2>

<p>The model defines the evolution of an asset price $S_t$ and its variance $v_t$ using the following system of stochastic differential equations:</p>

$$ dS_t = \mu S_t dt + \sqrt{v_t} S_t dW_{1,t} $$
$$ dv_t = \kappa(\theta - v_t)dt + \xi \sqrt{v_t} dW_{2,t} $$

<blockquote>
  <strong>Note:</strong> The two Wiener processes are correlated with parameter $\rho$, capturing the leverage effect where a drop in asset price is typically accompanied by a rise in volatility.
</blockquote>

<h2>2. Simulating the Heston Model</h2>

<p>To implement this in practice, we often use an Euler-Maruyama discretization. Below is a vectorized Python implementation using NumPy to simulate the asset price paths.</p>

<pre><code class="language-python">import numpy as np

def simulate_heston(S0, v0, mu, kappa, theta, xi, rho, T, N, M):
    """
    Simulates asset price paths under the Heston model.
    M: Number of time steps
    N: Number of simulation paths
    """
    dt = T / M
    
    # Initialize arrays
    S = np.zeros((M + 1, N))
    v = np.zeros((M + 1, N))
    
    S[0] = S0
    v[0] = v0
    
    # Generate correlated Brownian motions
    Z1 = np.random.normal(size=(M, N))
    Z2 = rho * Z1 + np.sqrt(1 - rho**2) * np.random.normal(size=(M, N))
    
    for t in range(M):
        # Ensure variance remains positive (Full Truncation scheme)
        v_pos = np.maximum(v[t], 0)
        
        # Discretize variance process
        v[t+1] = v[t] + kappa * (theta - v_pos) * dt + xi * np.sqrt(v_pos * dt) * Z2[t]
        
        # Discretize price process
        S[t+1] = S[t] * np.exp((mu - 0.5 * v_pos) * dt + np.sqrt(v_pos * dt) * Z1[t])
        
    return S, v
</code></pre>

<p>By simulating thousands of paths, we can approximate the expected payoff of exotic derivatives where closed-form solutions might be numerically unstable or unavailable.</p>
